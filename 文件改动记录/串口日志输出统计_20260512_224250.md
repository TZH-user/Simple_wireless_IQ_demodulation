## 关键结论

- `iq_amp` 与 `iq_pre` 当前存在部分重复：
  - `iq_pre.mi` 等于 `iq_amp.i_mean`
  - `iq_pre.mq` 等于 `iq_amp.q_mean`
  - `iq_pre.mag` 等于 `iq_amp.mag`
- 两者不完全等价：
  - `iq_pre.ph_urad` 是 IQ 预处理内部的相位累加/跟踪相位，不是以 `+I` 为 x 正半轴的绝对相位。
  - `iq_amp.ph_urad` / `iq_amp.ph_mdeg` 是按 `atan2(Q, I)` 计算的绝对相位，其中去中心后的 `I` 为 x 轴，`+I` 为 x 正半轴，去中心后的 `Q` 为 y 轴。
- 因此调试“矢量是否落在 x 正半轴”时，应优先看 `iq_amp.ph_mdeg`、`iq_amp.i_mean`、`iq_amp.q_mean`：
  - `ph_mdeg` 接近 `0` 表示靠近 `+I` 轴。
  - `i_mean > 0` 表示落在 x 正半轴。
  - `q_mean` 接近 `0` 表示垂直分量小。

## 幅度与相位单位说明

- `iq_pre.mi`、`iq_pre.mq`、`iq_amp.i_mean`、`iq_amp.q_mean`：
  - 单位是 ADC 原始码值差值，已经减去 ADC 中点，不是 mV。
  - 当前 ADC 为 14 bit，原始码值范围约 `0~16383`，默认中点约 `8192`。
  - 例如 `i_mean=541` 表示 I 路重心比 ADC 中点高约 541 个 ADC code。
- `iq_amp.i_amp`、`iq_amp.q_amp`：
  - 单位也是 ADC code。
  - 计算方式是 `abs(i_mean)`、`abs(q_mean)`，表示 I/Q 两个轴向分量的绝对幅度。
- `iq_pre.mag`、`iq_amp.mag`：
  - 单位是 ADC code。
  - 计算方式近似为 `sqrt(i_mean^2 + q_mean^2)`，表示去中心后 I/Q 重心矢量的合成幅度。
- `iq_rot.rh/rt/ch/ct`：
  - 单位是 ADC code 的累积矢量幅度，来自边缘窗口内多点求和后的幅度，不等同于单点电压或单点幅度。
- `adc_range.ivpp/qvpp`、`vpp`、`sig.v/p/n`、`sigdet_edge.p/v/t`：
  - 单位是 ADC 原始码值的峰峰值或由峰峰值计算出的阈值，仍然不是 mV。
- `iq_pre.fo_mhz`：
  - 字段名沿用历史命名，实际含义是 `residual_freq_millihz`，单位是 mHz。
- `iq_amp.ph_urad`：
  - 单位是微弧度，`1000000 urad = 1 rad`。
- `iq_amp.ph_mdeg`：
  - 单位是毫度，`1000 mdeg = 1 degree`。
  - 调试绝对相位时，`0 mdeg` 表示落在 `+I` 轴，`90000 mdeg` 表示约 `+90°`，`-90000 mdeg` 表示约 `-90°`。
- `iq_amp.ph_deg`：
  - 单位是度，固件直接输出三位小数，例如 `ph_deg=80.236`。
  - 该字段由 `ph_mdeg` 整数拆分得到，不依赖浮点 `printf`，便于串口人眼直接观察。

## 2026-05-13 新增相位 DPLL 调试日志

### `car`

示例：

```text
car,m=phase_lock,en=1,lk=1,pt=1,pv=1,pu=1,rf=91,uv=1570419,dc=1949,st=500
```

- `m`：当前载波闭环模式。`freq` 表示频率闭环，`phase_wait` 表示等待相位接管，`phase_lock` 表示相位环已经接管。
- `en`：相位闭环开关，1 表示编译配置允许相位接管。
- `lk`：锁定门控，1 表示扫频锁定后允许后级闭环。
- `pt`：相位接管状态，1 表示 VRFE 当前由相位环负责微调。
- `pv`：当前 block 的逐点相位圆均值是否可靠。
- `pu`：本次相位环是否实际写入了新的 DAC 电压。
- `rf`：IQ 预处理估计的残余频偏，单位 mHz；相位模式下主要作为保护退出条件。
- `uv`：当前 VRFE DAC 目标电压，单位 uV。
- `dc`：当前写入 DAC1 的 12-bit code。
- `st`：频率稳定累计 block 数，达到门限后允许相位接管。

### `carp`

示例：

```text
carp,deg=81.295,tg=90000,de=107,ctl=94991,du=-1,u=256,rel=1000
```

- `deg`：当前相位误差，单位度；这是相对 `tg` 的误差，不是绝对相位本身。
- `tg`：相位目标，单位毫度；当前 `90000` 表示目标 90 度。
- `de`：相邻有效 block 的相位误差变化量，单位毫度，用于判断相位是否仍在滑过目标。
- `ctl`：DPLL 合成控制量，单位毫度，等于相位误差叠加相位变化率阻尼后的结果。
- `du`：最近一次相位 DPLL 输出到 VRFE 的电压增量，单位 uV。
- `u`：逐点相位圆均值实际使用的采样点数；当前抽样配置下正常约为 256。
- `rel`：圆均值一致性，单位千分比；1000 表示相位高度集中。

### `carx`

示例：

```text
carx,fl=-23,lim=3,br=0,pc=1106,fc=901
```

- `fl`：相位模式下 residual 频偏低通值，单位 mHz；用于判断相位接管后频偏是否重新变大。
- `lim`：当前相位 DPLL 实际使用的单次 DAC 最大步进，单位 uV；目标近区内应降为 1。
- `br`：相位误差跨越目标后触发 trim 衰减的累计次数。
- `pc`：相位闭环实际写 DAC 的累计次数。
- `fc`：频率闭环实际写 DAC 的累计次数。
- 用途：判断当前是否已进入相位接管、是否在目标附近减速、以及相位模式内频率偏置是否失控。

### 本轮调试关注点

- 如果 `m=phase_lock` 且 `pt=1`，说明已经不是频率环在调 VRFE，而是相位环接管。
- 如果 `pv=1,u=256,rel=1000`，说明当前 CW 相位测量可靠。
- 如果 `du` 长时间为 0 而相位仍在转，说明控制量太弱或小数修正未累计到 DAC 最小可见步进。
- 如果 `du` 经常达到 `±2` 但相位仍穿过目标，说明需要继续调整阻尼、极性或修正范围。
- `iq_rot` 中 `ov=0,rb=0` 是本轮确认 ADC block 没有明显堆积的重要依据。

### `car`：模式与 DAC 基础状态

```text
car,m=phase_lock,en=1,lk=1,pt=1,pv=1,pu=0,rf=-12,uv=1560000,dc=1937
```

- `m`：闭环模式，`freq` 为频率闭环，`phase_wait` 为等待相位接管，`phase_lock` 为相位环接管。
- `en`：相位闭环开关。
- `lk`：锁定门控。
- `pt`：相位是否已经接管 DAC。
- `pv`：当前逐点相位圆均值是否有效。
- `pu`：本次是否允许相位环写 DAC。
- `rf`：当前 raw residual，单位 `mHz`。
- `uv`：当前 VRFE 控制电压，单位 `uV`。
- `dc`：当前 DAC code。

### `carp`：绝对相位与远区方向

```text
carp,ph=-12.345,tg=0,er=12.345,de=-20,fz=0,dir=1
```

- `ph`：逐点相位圆均值得到的绝对相位，单位 `deg`，0 度表示 `+I` 轴。
- `tg`：目标相位，单位 `mdeg`；本版为 `0`。
- `er`：到目标的相位误差，单位 `deg`；定义为 `wrap(target - current)`。
- `de`：相邻有效 block 的误差变化量，单位 `mdeg`。
- `fz`：是否处于 ±180 度远区方向保持。
- `dir`：远区方向保持值，`+1` 表示希望相位增加，`-1` 表示希望相位减小。

### `carx`：目标 residual 与 DAC 真实变化

```text
carx,fl=-8,tr=20,re=-28,du=100,dcd=1,chg=1,st=500
```

- `fl`：相位模式 residual 低通值，单位 `mHz`。
- `tr`：相位环根据当前相位误差生成的目标 residual，单位 `mHz`。
- `re`：`fl - tr`，单位 `mHz`；该值决定 DAC 往哪个方向修正。
- `du`：本次相位环请求的电压变化，单位 `uV`。
- `dcd`：最近一次 DAC code 变化量。
- `chg`：最近一次写 DAC 时 code 是否真实变化。
- `st`：频率稳定计数。

### `carq`：相位测量质量

```text
carq,u=256,rel=1000,pc=120,fc=900,le=0
```

- `u`：逐点相位平均实际使用的采样点数。
- `rel`：圆均值一致性，单位千分比；越接近 1000，说明相位越集中。
- `pc`：相位环写 DAC 次数。
- `fc`：频率环写 DAC 次数。
- `le`：最近一次 DAC HAL 操作错误码，0 表示正常。
