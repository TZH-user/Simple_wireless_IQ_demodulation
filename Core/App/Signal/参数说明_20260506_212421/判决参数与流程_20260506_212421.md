## 2. 判决顺序

当前 `app_moddet_classify()` 的顺序为：

1. 无载波：`carrier_present == 0` -> `NO_CARRIER`
2. ASK：强幅度变化 + 包络边沿 + 频率活动，或强包络分支成立 -> `ASK`
3. AM：幅度变化超过 AM 门限 -> `AM`
4. PSK：单符号偏置 + 频率活动上限内 + 频率或边沿条件 + 相位跳变 + 直方图峰数限制 + 包络变化低 -> `PSK`
5. FSK：单符号偏置 + 频率活动足够 + 相位跳变低 + 包络变化低 -> `FSK`
6. FM：频率活动超过 FM 门限 -> `FM`
7. 其他有载波低活动情况 -> `CW`

## 3. 判决流程

```text
ADC I/Q 双缓冲块
  -> 去直流 mean_i/mean_q
  -> 计算 mag2=ci^2+cq^2、env_min/env_max/mean_power
  -> 第二遍扫描：
       包络偏差 env_variation_pm
       包络边沿 env_edge_pm
       包络翻转 env_transition_cnt
       相邻 IQ cross/dot
       freq_activity/freq_bias
       positive/negative_freq_percent
       psk_jump_pm
       dphi_hist_peak_count
  -> app_moddet_classify() 得到瞬时 mode
  -> 按 mode 修正 rate/depth/dev/shift
  -> app_moddet_update_stable_mode() 得到 stable_mode/conf
  -> 串口 mod/ui 日志和 LVGL UI 显示
```

## 4. 参数估计流程

- AM rate：来自包络翻转计数，按 `2/5` 缩放；depth 来自包络幅度范围，按 `7/10` 修正。
- ASK rate：来自包络翻转计数，按 `1/3` 缩放；depth 直接取包络深度并限幅到 1000 pm。
- FM rate：来自频率符号翻转计数，按 `1/5` 缩放；dev 来自 `freq_activity`，按 `4/5` 缩放。
- FSK rate：来自频率符号翻转计数，按 `1/17` 缩放；shift 来自 `freq_activity`，按 `4/5` 缩放。
- PSK rate：来自 dot<0 相位跳变计数，按 `2/11` 缩放。
- CW：rate/depth/dev/shift 全部归零，避免 UI 显示假调制参数。

## 5. 当前准确率

最近一次闭环验证条件：

- RF：1.5 VPP，0 V 偏置。
- 频点：30 MHz、40 MHz、50 MHz。
- 类型：CW、AM 10 kHz 50%、ASK 10 kbps low=0、FM 10 kHz dev=75 kHz、FSK 10 kbps hop=+20 kHz、PSK 10 kbps 180°。
- 稳定模式 `stable_mode`：18/18 通过。
- 链路：18/18 命中 `fw_id`、`sigdet_final`、`mod` 扩展字段和 `ui` 代理字段。
- 参数量级：AM/ASK/FM/FSK/PSK/CW 均满足 UI 显示要求；FSK rate 波动最大，但 shift 更稳定。

## 6. 优势

- 不依赖 FFT，计算量低，适合 H743 当前实时任务链。
- 使用稳定投票，UI 不直接显示瞬时误判，显示更稳。
- CW 参数归零，避免无调制信号显示出假 rate/depth/dev。
- AM/ASK/FM/FSK/PSK 在当前题目参数下均能在约 1 秒内给出可用 UI 参数。
- 日志字段紧凑，小于打印队列单条 125 字节限制，避免压垮 AdcTask 栈和串口队列。

## 7. 劣势与边界

- 参数估计是经验缩放，不是仪表级测量；换采样率、滤波器、幅度或锁定误差后需要重新标定。
- FSK rate 对码型、符号翻转密度和差频锁定较敏感，当前更建议相信 `fsk_shift_hz`。
- AM depth 在端点频率会受硬件幅频响应和锁定点影响，能反映强弱但不是精密深度计。
- 当前没有 Goertzel/FFT 或自相关，不适合要求高精度调制率/频偏的场景。
- 当前验证集中未覆盖 0.75/1.0/2.0 VPP、1k/5k/20k 速率，扩展参数范围前应重新采矩阵。
