# 特征参数说明

- 时间戳：20260506_212421
- 源码位置：`Core/App/Signal/app_mod_detect.h`、`Core/App/Signal/app_signal_detect.h`
- 计算入口：`app_mod_detect_process_iq_block()`、`app_signal_detect_process_block()`
- 说明：本文只记录当前已进入状态结构、日志或 UI 的特征参数；中间临时变量只在“来历”中说明。

## 1. 调制识别特征参数

| 参数 | 来历 | 计算方式 | 作用 |
|---|---|---|---|
| `mode` | `app_moddet_classify()` 输出 | 按 ASK/AM/PSK/FSK/FM/CW 的规则顺序判决 | 瞬时调制类型，用于调试和稳定投票输入 |
| `block_count` | `g_moddet.status.block_count + 1` | 每处理一个 ADC 半缓冲 IQ 块加 1 | 判断算法是否持续运行，配合日志抽样 |
| `ac_power` | I/Q 去均值后的功率 | `mean_power = sum(ci^2+cq^2)/sample_cnt` | 载波存在判定、其他特征归一化基准 |
| `env_variation_pm` | 包络功率偏离均值的程度 | `avg(abs(mag2-mean_power))/mean_power*1000` | 幅度类识别核心特征，AM/ASK 会高 |
| `env_edge_pm` | 包络突变次数 | `env_edge_cnt/(sample_cnt-1)*1000` | ASK 边沿和 PSK/ASK 瞬态活动参考 |
| `freq_activity` | 相邻 IQ 向量相位活动 | `avg(abs(cross))/mean_power*1000` | FM/FSK/PSK 频率/相位活动强度 |
| `freq_bias` | 相邻 IQ 向量叉积平均值 | `sum(cross)/(sample_cnt-1)` | 判断差频方向，观察单边偏置 |
| `fsk_balance_pm` | 正负频率活动总覆盖度 | `(positive_freq_cnt+negative_freq_cnt)/(sample_cnt-1)*1000` | 辅助观察 FSK/FM 是否有频率符号活动 |
| `psk_jump_pm` | 相位反向跳变密度 | `dot<0` 的次数除以 pair 数再乘 1000 | PSK 180° 判断核心特征 |
| `modulation_rate_hz` | 边沿/频率符号/相位跳变计数 | 原始计数按采样率换算，再按调制类型经验缩放 | UI 显示 AM/FM 调制率或 ASK/FSK/PSK 符号率 |
| `am_depth_pm` | 包络幅度最小/最大值 | `sqrt(env_max/min)` 后 `(max-min)/(max+min)*1000`，再按模式修正 | UI 显示 AM 深度或 ASK 幅度深度 |
| `fm_deviation_hz` | `freq_activity` 估算 | `freq_activity*sample_rate/6283` 后按模式缩放 | UI 显示 FM 频偏；FSK 模式下作为 shift 副本 |
| `fsk_shift_hz` | FSK 模式下 `raw_dev_hz` 缩放 | 当前约 `raw_dev_hz*4/5` | UI 显示 FSK 两频点间隔估计 |
| `stable_mode` | 稳定投票器 | 各模式票数衰减，当前 `mode` 加权，取最高票 | UI 显示的主模式，抑制瞬时误判 |
| `stable_confidence_percent` | 稳定投票器 | `best_vote/total_vote*100` | UI 判断稳定模式可信度 |
| `env_level_count` | 包络幅度分箱 | 将 `mag2` 映射到 8 个 bin，统计占用 bin 数 | 观察包络分布复杂度，辅助调试 ASK/AM |
| `dphi_hist_peak_count` | 相位差直方图 | 按相位差正负/强弱分 5 桶，统计有效峰 | 辅助区分 FSK/PSK/FM |
| `positive_freq_percent` | `cross>0` 计数 | `positive_freq_cnt/(sample_cnt-1)*100` | 单符号频率偏置判断 |
| `negative_freq_percent` | `cross<0` 计数 | `negative_freq_cnt/(sample_cnt-1)*100` | 单符号频率偏置判断 |
| `carrier_present` | `ac_power` 门限 | `ac_power >= APP_MODDET_MIN_AC_POWER` | 无载波时禁止输出有效调制结论 |

## 2. 扫频/载波锁定特征参数

| 参数 | 来历 | 计算方式 | 作用 |
|---|---|---|---|
| `scanning` | 扫频状态机 | 开始扫频置 1，锁定结束置 0 | UI 显示是否正在搜索 |
| `carrier_present` | Vpp 响应有效性 | 峰谷差、阈值边沿满足条件后置 1 | 判断是否检测到载波 |
| `stage` | 扫频状态机 | 0 粗扫、1 细扫、2 锁定 | 控制后续调制识别启动 |
| `locked` | 锁定结果 | `carrier_present` 且扫频结果可信时置 1 | 调制识别启动门控 |
| `current_lo_hz` | DDS/LO 当前频点 | 扫频时按步进更新，锁定后写 final_hz | UI 显示本振频率 |
| `estimated_carrier_hz` | Vpp 响应曲线估算 | 左右边沿中点或谷点估计，锁定后修正 | UI 显示载波频率 |
| `current_vpp_raw` | 当前频点总 Vpp | I/Q 当前块 Vpp 综合或平均 | 扫频曲线响应值 |
| `current_i_vpp_raw` | I 路当前 Vpp | I 路 ADC 块内 `max-min` | I 路链路诊断 |
| `current_q_vpp_raw` | Q 路当前 Vpp | Q 路 ADC 块内 `max-min` | Q 路链路诊断 |
| `peak_vpp_raw` | 扫频最大响应 | 扫频过程中逐点取最大 | 计算阈值和诊断响应强度 |
| `valley_vpp_raw` | 扫频最小响应 | 扫频过程中逐点取最小 | 载波附近低点定位 |
| `threshold_vpp_raw` | 有效边沿阈值 | `valley + max((peak-valley)/4, min_rise)` | 找左右边沿 |
| `left_edge_hz` | 左边沿频率 | 从谷点向左搜索首次越过阈值的点 | 与右边沿求中点估计载波 |
| `right_edge_hz` | 右边沿频率 | 从谷点向右搜索首次越过阈值的点 | 与左边沿求中点估计载波 |
| `scan_start_tick_ms` | RTOS tick | 扫频开始 `osKernelGetTickCount()` | 统计搜索耗时 |
| `scan_finish_tick_ms` | RTOS tick | 锁定结束 `osKernelGetTickCount()` | 统计搜索耗时 |
| `step_index` | 当前扫频点 | 每完成一个频点递增 | 日志显示扫描进度 |
| `step_count` | 总扫频点数 | `(stop-start)/step+1` | 日志显示总点数 |
| `valley_step_index` | 谷点索引 | 更新 `valley_vpp_raw` 时记录 | 载波谷点定位 |
| `peak_step_index` | 峰点索引 | 更新 `peak_vpp_raw` 时记录 | 响应强度诊断 |

## 3. 日志对应关系

- `mod,mode=...,stable=...,conf=...,rate=...,depth=...,dev=...,shift=...`：来自 `app_mod_detect.c`，是 UI 代理和调参主日志。
- `ui,mode=...,inst=...,conf=...,rate=...,depth=...,dev=...,shift=...`：来自 `app_mod_detect.c`，模拟屏幕使用的稳定模式参数。
- `mod,m=...,ac=...,env=...,edge=...,fq=...,psk=...,hist=...`：来自 `AdcTask.c` 的 1 秒健康日志，主要用于低频健康观察。
- `sigdet_final,final_lo=...,estimated_carrier=...,peak=...,valley=...,threshold=...,left_edge=...,right_edge=...,locked=...`：来自 `app_signal_detect.c`，用于载波搜索最终结果。
